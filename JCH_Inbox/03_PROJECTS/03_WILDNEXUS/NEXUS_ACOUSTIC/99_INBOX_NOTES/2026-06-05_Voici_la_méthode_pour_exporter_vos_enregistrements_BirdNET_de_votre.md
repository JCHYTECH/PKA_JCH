# Voici la méthode pour exporter vos enregistrements BirdNET de votre…

> Exporté depuis Apple Notes — créé le ?, modifié le 2026-06-05 05:54

�1�1�Voici la méthode pour exporter vos enregistrements BirdNET de votre téléphone vers un ordinateur afin de les nettoyer :
1. Exporter un fichier audio précis depuis l'application [1] 
Pour récupérer la bande sonore d'une observation et la transférer sur votre ordinateur, suivez ces étapes : [1, 2, 3] 

Ouvrez le menu principal de BirdNET (les 3 lignes horizontales ☰ en haut à gauche).
Sélectionnez "Afficher les observations" (ou Show observations).
Appuyez sur l'observation contenant le chant que vous souhaitez nettoyer.
Touchez l'icône "Partager" (souvent représentée par trois points reliés ou une flèche).
Choisissez de l'envoyer vers votre Cloud (Google Drive, iCloud, OneDrive) ou directement par E-mail.
Note : Si le fichier téléchargé sur votre ordinateur n'a pas d'extension lisible, ajoutez simplement .wav à la fin du nom de votre fichier pour qu'il soit reconnu par vos logiciels audio. [2, 3, 4, 5] 
(Si vous souhaitez plutôt exporter la totalité de vos données et listes d'observations en une fois, vous pouvez cliquer sur les trois petits points ⋮ en haut à droite de l'écran des observations, puis choisir "Exporter les observations"). [2] 

2. Nettoyer le bruit de fond sur votre ordinateur [4] 
Une fois le fichier .wav récupéré sur votre PC ou Mac, vous pouvez utiliser un logiciel de traitement audio gratuit comme Audacity pour supprimer les bruits parasites : [2] 

Importer le fichier : Ouvrez Audacity et glissez-y votre fichier audio. [1, 4] 
Isoler le bruit : Sélectionnez à la souris une zone de 1 ou 2 secondes où l'on entend uniquement le bruit de fond (le vent, la pluie, un moteur), sans aucun chant d'oiseau.
Capturer le profil du bruit : Allez dans le menu Effets > Réduction de bruit > Cliquez sur "Prendre le profil du bruit".
Appliquer le filtre : Sélectionnez ensuite l'intégralité de votre bande sonore (Ctrl + A), retournez dans Effets > Réduction de bruit, puis cliquez sur "Valider".
Le logiciel va automatiquement gommer le bruit de fond continu pour faire ressortir la pureté du sifflement de l'oiseau.
