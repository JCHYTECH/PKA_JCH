① Ce que ça fait

Camping Scout est une mini-application web qui tourne sur ton Mac ou un Raspberry Pi dans le van. Tu y accèdes depuis ton iPhone comme un site web, sans installer quoi que ce soit sur le téléphone.

FonctionnalitéComment
🔍 Chercher des spots autour d'un lieuTu tapes "Honfleur", tu obtiens tous les campings, aires CC et parkings motorhome dans le rayon choisi
📍 Chercher depuis ta position GPSBouton "Ici" → le téléphone donne sa position → résultats triés du plus proche au plus loin
🔄 Mise à jour automatiqueSi tu roules, la liste se rafraîchit tous les 300m
💶 Prix affichéQuand OSM le connaît (environ 1 spot sur 4)
★ Score JCHNote 0–10 selon la proximité d'une réserve naturelle (pour photo aube)
🗺️ Google MapsBouton sur chaque spot → s'ouvre dans Google Maps avec l'itinéraire

② Matériel nécessaire

Scénario A — Mac dans le van

Ce qu'il faut
  • Ton MacBook (branché sur le van ou batterie externe)
  • iPhone avec 4G
  • C'est tout — rien à acheter

Inconvénient Le Mac doit rester allumé. Consomme 30–60W.

③ Schéma des connexions

── Dans le van ──────────────────────────────────────────────── 📱 iPhone │ ├─ Partage de connexion (hotspot 4G) │ → le RPi/Mac s'y connecte via WiFi │ → le RPi obtient internet pour faire ses recherches │ └─ Navigateur Safari → http://192.168.x.x:5050 → accède à l'app Camping Scout sur le RPi 🔴 Raspberry Pi (ou Mac) │ ├─ WiFi → connecté au hotspot iPhone (pour Overpass/internet) ├─ Flask → sert l'interface web sur le réseau local └─ Cache SQLite → si perte de signal, les derniers résultats restent ───────────────────────────────────────────────────────────────── Résumé : iPhone donne internet au RPi iPhone accède à l'app du RPi Le tout sur le même réseau hotspot
⚠️ L'iPhone doit avoir la 4G pour que les recherches fonctionnent. En zone blanche, le cache affiche les derniers résultats chargés (10 min de rétention).

④ Installation sur le Mac — une seule fois

1
Ouvrir le Terminal Spotlight → taper "Terminal" → Entrée
2
Installer les dépendances Python
pip install flask requests geopy --break-system-packages
3
Tester que tout fonctionne
python3 ~/PKA_JCH/scripts/camping_server.py 🏕️ Camping Scout — serveur démarré Local : http://localhost:5050 Réseau : http://192.168.x.x:5050
Ouvrir http://localhost:5050 dans Safari → l'app apparaît.
4
Arrêter le serveur Dans le Terminal : Ctrl + C

⑤ Installation sur Raspberry Pi — une seule fois

Étape 1 — Préparer la carte SD

1
Télécharger Raspberry Pi Imager raspberrypi.com/software → installer sur le Mac
2
Flasher la carte SD Ouvrir RPi Imager → choisir "Raspberry Pi OS Lite (64-bit)" → sélectionner la carte SD
Avant de flasher, cliquer sur ⚙️ Options avancées et configurer :
  • Hostname : camping-van
  • Activer SSH : oui (mot de passe)
  • Utilisateur : pi / mot de passe : ton choix
  • WiFi : nom de ton hotspot iPhone + mot de passe iPhone
  • Timezone : Europe/Brussels
3
Démarrer le RPi Insérer la carte SD → brancher le RPi → attendre 60 secondes

Étape 2 — Se connecter et installer

Depuis le Mac, avec le RPi connecté au même WiFi :

# Connexion SSH au RPi ssh pi@camping-van.local # Mettre à jour le système sudo apt update && sudo apt upgrade -y # Installer Python et pip sudo apt install python3-pip -y # Installer les dépendances pip3 install flask requests geopy # Créer le dossier PKA sur le RPi mkdir -p ~/camping_scout

Étape 3 — Copier le script depuis le Mac

# Sur le Mac, dans le Terminal : scp ~/PKA_JCH/scripts/camping_server.py pi@camping-van.local:~/camping_scout/

Étape 4 — Démarrage automatique (optionnel mais recommandé)

Pour que l'app démarre automatiquement quand le RPi s'allume :

# Sur le RPi (via SSH) : sudo nano /etc/systemd/system/camping-scout.service # Coller ce contenu : [Unit] Description=Camping Scout After=network.target [Service] User=pi WorkingDirectory=/home/pi/camping_scout ExecStart=/usr/bin/python3 /home/pi/camping_scout/camping_server.py Restart=always RestartSec=5 [Install] WantedBy=multi-user.target
# Activer et démarrer le service : sudo systemctl enable camping-scout sudo systemctl start camping-scout # Vérifier que ça tourne : sudo systemctl status camping-scout ● camping-scout.service - Camping Scout Active: active (running)

⑥ Utilisation au quotidien dans le van

1
Activer le hotspot iPhone Réglages → Partage de connexion → Activer
2
Démarrer le serveur
Sur Mac : ouvrir le Terminal et lancer python3 ~/PKA_JCH/scripts/camping_server.py
Sur RPi : rien à faire — démarre automatiquement à l'allumage
3
Trouver l'IP du serveur Le Terminal affiche au démarrage :
Réseau : http://192.168.x.x:5050 ← depuis le téléphone
💡 Sur RPi, l'IP change selon le hotspot. Pour avoir toujours la même : attribuer une IP fixe dans les réglages hotspot iPhone (avancé → DHCP).
4
Ouvrir depuis l'iPhone Safari → taper l'adresse http://192.168.x.x:5050
→ Ajouter à l'écran d'accueil (partage → "Sur l'écran d'accueil") pour l'avoir comme une app
5
Rechercher des spots Taper le nom d'un lieu → Chercher → la carte et la liste apparaissent, triés par distance

⑦ Mode Plan B — spot barré ou inaccessible

Situation : tu arrives sur le spot prévu → barrière, propriété privée, trop étroit, complet.
1
Appuyer sur "📍 Ici" L'iPhone détecte ta position GPS exacte
2
Résultats mis à jour automatiquement Tous les spots dans 10 km autour de toi, triés du plus proche au plus loin
3
Ajuster le rayon si besoin Slider en haut → 2 à 25 km — les résultats se mettent à jour
4
Choisir un spot et y aller Bouton Google Maps → sur le spot choisi → s'ouvre dans Google Maps avec l'itinéraire complet
💡 Si tu roules — la liste se rafraîchit automatiquement toutes les 300m de déplacement (avec minimum 30 secondes entre deux requêtes). Tu n'as rien à faire.

⑧ Dépannage

ProblèmeCause probableSolution
"ERR_CONNECTION_REFUSED" sur l'iPhone Le serveur n'est pas démarré, ou mauvaise IP Relancer camping_server.py sur le Mac/RPi. Vérifier l'IP affichée dans le Terminal.
0 résultats Overpass API non accessible (pas de 4G) Vérifier que le hotspot iPhone est actif. Attendre 30s et relancer une recherche.
GPS ne fonctionne pas (bouton "Ici") Safari n'a pas l'autorisation de géolocalisation Réglages iPhone → Safari → Localisation → Autoriser
iPhone ne trouve pas l'IP du RPi Le RPi n'est pas connecté au hotspot Vérifier que le nom du hotspot iPhone correspond à celui configuré sur le RPi (sensible à la casse).
Le RPi ne démarre pas le service Erreur dans le script ou dépendances manquantes sudo systemctl status camping-scout → lire l'erreur. Relancer pip3 install flask requests geopy
Port 5050 déjà utilisé sur Mac AirPlay Receiver occupe le port 5000 (on a évité avec 5050) Normalement résolu. Si persistant : Réglages Système → AirDrop & Handoff → désactiver Récepteur AirPlay.
Prix manquants sur les spots OSM ne connaît les prix que pour ~25% des spots Normal. Pour plus de données : installer Playwright (niveau 2) → park4night donne souvent les prix.
Commandes de référence rapide
# Démarrer le serveur (Mac) python3 ~/PKA_JCH/scripts/camping_server.py # Recherche rapide en ligne de commande python3 ~/PKA_JCH/scripts/camping_scout.py --location "Honfleur" --radius 15 --quick --save # Statut du service RPi sudo systemctl status camping-scout # Redémarrer le service RPi sudo systemctl restart camping-scout # Voir les logs RPi (erreurs) journalctl -u camping-scout -f
