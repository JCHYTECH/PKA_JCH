# OMBRIE EN MINIVAN – GUIDE PRATIQUE

## 🚐 SPELLO (Village fleuri)

**1. ACCÈS**
- Route principale : **SR75** (Strada Regionale) depuis Assise (12 km)
- Type : route régionale bien entretenue, 2 voies
- **Praticabilité 2m ✓** : OUI, pas de problème de hauteur
- Centre-ville historique : accès étroit aux ruelles pavées (à éviter avec le minivan)

**2. PARKING**
- **Parking Belvedere** (entrée nord) : gratuit, ~50 places
  - Hauteur : à vérifier sur place
  - Distance centre : 200m (montée à pied)
- **Parking via Centrale** : payant, ~€1,50/heure (à vérifier)
- Préférence : Belvedere pour vue panoramique

**3. NUIT SUR PLACE**
- Camping-car **NON autorisé** en centre-ville
- Aire officielle la plus proche : **Campeggio Spello** (camping 3-étoiles)
  - Distance : 1,5 km du centre
  - Tarif : ~€25-35/nuit (à vérifier saison)
  - Services : eau, électricité, vidange ✓
- Stationnement nocturne toléré : parking Belvedere possible (à confirmer avec mairie)

**4. SERVICES**
- **Borne eau/électricité/vidange** : Campeggio Spello (1,5 km)
- **Supermarché Conad** : via Centrale, 500m du centre
- **Pharmacie/essence** : centre-ville

**5. ASTUCE VANLIFE**
- **Meilleure saison** : avril-mai (floraisons) ou septembre-octobre
- **Durée visite** : 2-3 heures (village petit)
- **Meilleure heure photos** : 7h-9h (lumière douce, moins de touristes)
- **Spot secret** : ruelle via Cappuccini (fleurs moins photographiées)

## 🏺 DERUTA (Céramiques)

**1. ACCÈS**
- Route : **SR3** (Strada Regionale Umbra Superiore) depuis Pérouse (30 km)
- Type : route régionale, 2-3 voies, bien balisée
- **Praticabilité 2m ✓** : OUI, route dégagée
- Centre artisanal accessible en minivan

**2. PARKING**
- **Parking Piazza dei Consoli** : gratuit, ~30 places
  - Hauteur : à vérifier
  - Centre-ville : 100m
- **Parking Viale Vasari** : payant, ~€0,80/heure, plus spacieux
- Conseil : arriver avant 10h pour places gratuites

**3. NUIT SUR PLACE**
- Camping-car : possible mais limité
- **Aire camping-car officielle** : à vérifier (commune parfois tolérante)
- Camping 3km : **Camping Deruta** 
  - Tarif : ~€20-30/nuit
  - Services complets ✓
- Stationnement nocturne : à demander à la mairie locale

**4. SERVICES**
- **Borne eau/électricité** : Camping Deruta (3 km)
- **Supermarché Coop** : via Maestri della Ceramica, 1 km
- Essence : via Tiberina (zone commerciale)

**5. ASTUCE VANLIFE**
- **Meilleure saison** : mai-septembre (ateliers artisanaux actifs)
- **Durée visite** : 2-4 heures (musée + ateliers)
- **Meilleure heure** : 9h-11h (artisans au travail, moins chaud)
- **Spot secret** : atelier Grazia Deruta (demander adresse, production traditionnelle)

## 💧 STIFONE (Piscines naturelles)

**1. ACCÈS**
- Route : **SR448** depuis Terni (25 km), puis **SP209** locale
- Type : route régionale + petite route de campagne
- **Praticabilité 2m ✓** : OUI mais derniers 2 km étroits
- Attention : route de campagne non asphaltée (à vérifier après pluie)

**2. PARKING**
- **Parking naturale Stifone** (officiel, à l'entrée)
  - Gratuit, ~40 places
  - Hauteur : pas de barrière (2m OK)
  - Accès direct aux piscines : 5 min à pied
- Conseil : arriver tôt (parking complet en été à partir de 11h)

**3. NUIT SUR PLACE**
- Camping-car : **NON autorisé** sur parking
- Aire officielle : **Campeggio Cascata delle Marmore** (10 km)
  - Campingcarservice recommandé
  - Tarif : ~€18-25/nuit
- Stationnement nocturne : à demander à Commune de Montecchio (non garanti)

**4. SERVICES**
- **Borne** : Campeggio Cascata (10 km)
- **Supermarché** : Coop à Montecchio (8 km)
- Essence : station à Terni (30 km)

**5. ASTUCE VANLIFE**
- **Meilleure saison** : juin-août (eau chaude naturelle ~25°C)
- **Durée visite** : 3-4 heures (baignade + détente)
- **Meilleure heure** : 7h-9h (éviter foule, eau plus claire le matin)
- **Spot secret** : la grotte thermale cachée (demander aux locaux à l'accueil)

## 🏰 NARNI (Village médiéval)

**1. ACCÈS**
- Route : **A1** (autoroute, sortie Narni-Amelia) ou **SR3**
- Via **SR3** (route régionale) : 45 km depuis Pérouse, plus pittoresque
- **Praticabilité 2m ✓** : OUI (SR3), autoroute sans souci
- Centre-ville : ruelles pavées étroites (parking externe recommandé)

**2. PARKING**
- **Parking Largo Maglione** : gratuit, ~50 places
  - Hauteur : OK
  - Centre-ville : 300m (escaliers)
- **Parking via Garibaldi** : payant, ~€1/heure, spacieux
- Préférence : Garibaldi pour minivan

**3. NUIT SUR PLACE**
- Camping-car : limité
- **Campeggio Nera Camping** : 3 km du centre
  - Tarif : ~€20-28/nuit
  - Services complets ✓
- Stationnement toléré : sur parking Garibaldi (à confirmer)

**4. SERVICES**
- **Borne eau/électricité** : Nera Camping (3 km)
- **Supermarché Conad** : piazza Garibaldi, centre-ville
- Essence : via della Stazione

**5. ASTUCE VANLIFE**
- **Meilleure saison** : septembre-octobre, avril-mai (climat idéal, moins touristique)
- **Durée visite** : 3-5 heures (château, église, musée)
- **Meilleure heure** : 8h (château lumineux), puis 16h-18h (centre doré)
- **Spot secret** : Loggia dei Priori (terrasse vue Valle del Nera, rarement bondée)
