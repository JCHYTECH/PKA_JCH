# Guide Pratique Minivan — Trio de Joyaux Médiévaux de Charente-Maritime

## ⚠️ Préambule important
Le "Trio de joyaux médiévaux" de Charente-Maritime n'est pas une dénomination officielle standardisée. Les trois sites les plus probables sont :
- **Château de Montendre** (Montendre)
- **Abbaye de Fontdouce** (Saint-Abin)
- **Château de Crazannes** (Crazannes)

*Les informations ci-dessous couvrent ces trois sites. À vérifier auprès de l'office de tourisme local pour confirmer le trio visé.*

---

## 1️⃣ **ACCÈS & PRATICABILITÉ MINIVAN (2m hauteur)**

### Château de Montendre
- **Route d'accès** : D730 depuis Montendre (commune)
- **Type** : Routes départementales, bon état général
- **Praticabilité** : ✅ Oui, pas de restriction de hauteur signalée
- **Distance approximative** : 50 km de Rochefort (axe principal N137)

### Abbaye de Fontdouce (Saint-Abin)
- **Route d'accès** : D124 via Saint-Abin
- **Type** : Route départementale, passages étroits possible
- **Praticabilité** : ✅ Oui, mais **à vérifier sur place** — accès final parfois sinueux
- **Distance** : 70 km de La Rochelle (via N137)

### Château de Crazannes
- **Route d'accès** : D114 via Crazannes
- **Type** : Route départementale, bien balisée
- **Praticabilité** : ✅ Oui, bon état
- **Distance** : 65 km de Rochefort

## 5️⃣ **ASTUCE VANLIFE**

### 📅 **Meilleure saison**
- **Avril-mai** : fleurs, climat doux, affluence modérée
- **Septembre-octobre** : soleil, touristes moins nombreux ⭐ **À préférer**
- ❌ Juillet-août : très chaud en van (2m = ventilation limitée), parking bondés

### ⏱️ **Durée visite recommandée**
- **Montendre** : 1-1h30 (château + promenade)
- **Fontdouce** : 1h-1h30 (abbaye + cloître)
- **Crazannes** : 1h (château exterior)
- **Total circuit** : 2-3 jours confortablement

### 📸 **Heure idéale photos**
- **Matin** (7h-9h) : lumière douce, absence touristes
- **Fin d'après-midi** (16h-18h) : ombre/lumière contrastée, site vidé
- ❌ Midi (12h-14h) : ombre trop dure

### 🎯 **Spot secret vanlife**
- **Abbaye de Fontdouce** : les jardins internes offrent ambiance + relative tranquillité
- **Itinéraire alternatif** : coupler avec les marais de Brouage (30 km), moins touristique
- **Bivouac improvisé** : petites routes agricoles entre Crazannes et Montendre (à respecter propriétés)
