# CAPPELLA BAGLIONI (Spello, Ombrie) — Guide Pratique Minivan

## 1. ACCÈS

**Itinéraire principal :**
- Depuis l'autoroute A1 : sortie **Valdichiana** (environ 40 km)
- Route : **SR75** (Strada Regionale) → **SP446** → centre historique de Spello
- **Type de route** : SR75 = route nationale à 2 voies (bonne état). SP446 = route départementale étroite mais praticable
- **État** : bien entretenu, mais attention aux virages serrés en montée vers Spello
- **⚠️ Praticabilité 2m de haut** : ✅ **OUI**, mais le centre-ville historique comporte des passages très étroits. Accès recommandé en **stationnement périphérique** (voir parking)
- **Distance depuis Assise** : 12 km | **Depuis Pérouse** : 35 km

---

## 2. PARKING

**Problème principal** : Spello est un bourg médiéval fortifié = centre-ville extrêmement étroit (rues < 3,5m).

### Parking conseillé pour minivan :
- **Parcheggio Belvedere** (officiel, entrée sud de Spello)
  - Hauteur max : **2,1 m** ✅ (limite très proche — déjà signalée comme "à risque" pour camping-cars)
  - Tarif : **gratuit** (hors saison estivale)
  - Distance à pied vers Santa Maria Maggiore : **700 m** (montée raide)
  - Accès : coordonnées GPS **42.9065, 12.6642**

- **Parking Porta Romana** (alternative)
  - Hauteur max : **à vérifier sur place**
  - Tarif : gratuit
  - Distance : 900 m vers la chapelle

### ⚠️ À éviter :
- Les petits parkings du centro storico (hauteur 1,9 m max, passages piétons étroits)

---

## 3. NUIT SUR PLACE

**Camping-car officiel dans Spello même** : ❌ **NON autorisé** (stationnement de nuit interdit centre-ville)

### Solutions proches :

**AIRE DE CAMPING-CAR OFFICIELLE :**
- **Parcheggio Belvedere** : tolère généralement le stationnement nocturne en basse saison (mai-juin, sept-oct), **à confirmer** auprès de l'office de tourisme Spello : +39 0742 301009
- Pas d'services (eau/élec/vidange) sur place

### Alternatives recommandées :

1. **Camping Rio Verde** (Spello)
   - Distance : 2 km (route D446)
   - Services complets : eau, électricité, vidange, Wi-Fi
   - Tarif approximatif : **25-35 €/nuit** (camping-car)
   - Tél. : +39 0742 651057
   - ✅ Accepte les camping-cars (hauteur : 2,2 m)

2. **Agriturismos avec aire parking** (fermes-auberges ombriennes)
   - À 5-10 km : nombreuses propositions en plain air
   - Tarif : 15-30 € (à négocier directement)
   - À vérifier via **Booking** ou **Park4night**

**Stationnement nocturne toléré ?** : Très risqué ; préférer camping ou aire officielle.

## 4. SERVICES

### Borne eau/électricité/vidange :
**Rio Verde Camping** (voir ci-dessus)
- Distance : **2 km**
- Tarif vidange : **5 € environ** (clients non-camping)

**Alternative − Aire de service Spoleto** (18 km, plus grande ville)
- Aire service : Via del Ponte (vérifier accès hauteur)
- Tarif vidange : ~8 €

### Supermarché :
- **Conad** (chaîne locale)
  - Via Garibaldi, Spello — distance : **1,2 km** du Parcheggio Belvedere
  - Horaires : 8h30-20h (fermé dimanche après-midi)
  - Petit supermarché, fruits/légumes locaux OK

- **Carrefour Express** : Porta Romana (centre)
  - Distance : 900 m | Horaires standards

### Carburant :
- **Distributeur Eni** : À l'entrée de Spello (SP446)
  - Distance : 1,5 km du parking

## 5. ASTUCE VANLIFE

### 🌞 **Meilleure saison** :
- **Mai-juin** : fleurs (Spello = fête des fleurs juin) + climat parfait
- **Septembre-octobre** : moins de touristes, lumière dorée
- ❌ Éviter juillet-août (très chaud, beaucoup de monde)

### ⏱️ **Durée visite recommandée** :
- **Cappella Baglioni** : 30-45 min (intense, fresques à observer longtemps)
- **Église Santa Maria Maggiore + resto/café** : 2-3h total

### 📸 **Heure idéale pour photos** :
- **9h-10h** : lumière du matin, peu de touristes dans la chapelle
- **16h-17h** : lumière rasante sur fresques Pinturicchio (dorée), moins de groupes

### 🔑 **Spot secret** :
- **Via Cavour** (en montant vers l'église) : petite piazza cachée avec vue sur la vallée d'Assise — parfait pour pause camping-car + photo panorama
- Les **fresques extérieures de Spello** (façades peintes) : gratuit, autour du centro

### 📋 **À faire avant d'arriver** :
1. Appeler **Rio Verde Camping** pour réserver (juillet-août surtout)
2. Téléphoner à l'office de tourisme Spello : **+39 0742 301009** (confirmer accès parking hauteur)
3. Consulter **Park4night** pour retours utilisateurs minivans récents
4. Acheter tickets église en ligne si possible (évite files)

### 🎫 **Tarif entrée Cappella** :
- Entrée généralement **libre** (donation suggérée 2-3 €) ou incluse ticket église
- À vérifier : +39 0742 301009
