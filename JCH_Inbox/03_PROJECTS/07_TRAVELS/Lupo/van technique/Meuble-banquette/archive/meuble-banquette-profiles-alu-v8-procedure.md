# Procédure de construction — Meuble banquette v8 (aluminium T-slot 2020 · équerre 3 voies iMetrx)

> Construction par phases. Outillage : scie à métaux (ou mini-meuleuse), clé Allen, cutter, tournevis, équerre, mètre, lime. Perceuse optionnelle.
> Références : `meuble-banquette-profiles-alu-v8.md` (design) · `meuble-banquette-profiles-alu-v8-plan.svg` (plan) · `meuble-banquette-profiles-alu-v8-coupes.xlsx` (coupes/BOM).

---

## Phase 0 — Préparation (coupes + commandes)

1. **Profilés** : couper les **44 profilés 2020** selon la liste de coupes :
   - rails profondeur **540 mm** (passants), rails largeur **304/248 mm** (butés), montants **216 mm**.
   - Scie à métaux, trait droit, aucun onglet.
2. **Panneaux** : faire découper par le fournisseur :
   - Dibond 3 mm : fonds (304×500 / 248×500), côtés (500×216), volets (304×216 / 248×216).
   - HPL compact 12 mm : 3 tables/assises, angles avant arrondis R5–R10 (CNC).
3. **Quincaillerie** : coulisses Chambrelan D5DD (3 paires), **24 équerres 3 voies iMetrx** (vis + clé incluses), T-nuts M4, charnières piano (6), loquets à bascule (6), visserie inox.
4. **Vérifier** : A = 344 / B = C = 288 de large ; rails largeur A = 304, B/C = 248.

> **Règle de coupe (chaîne dimensionnelle fermée)** : rail buté = largeur extérieure − 2×20 (les deux rails de profondeur). Rail passant = cote extérieure pleine. Montant = hauteur − 2×20. Boucle fermée : `344 = 304 + 2×20` · `288 = 248 + 2×20` · `256 = 216 + 2×20`.

---

## Phase 1 — Construction métallique (ossature)

*Objectif : 3 cages 2020 carrées, sans panneaux.*

1. **Assembler la base** : 2 rails profondeur (540) + 2 rails largeur (304 ou 248) reliés par **4 équerres 3 voies** aux coins (insérées dans la rainure, vis serrées modérément). Les rails largeur viennent **buter** contre les rails profondeur.
2. **Monter les 4 montants** (216 mm) sur les équerres de la base.
3. **Poser le cadre haut** : 4 rails + 4 équerres 3 voies. Vérifier que les montants rentrent.
4. **Équerrage** : contrôler les diagonales avant de serrer à fond.
5. **Répéter** pour les 2 autres modules.
6. **Solidarisation (optionnelle au banc)** : A + B + C via chevilles Ø8 + loquets, une fois les 3 cages alignées.

> ⚠️ Ne pas trop serrer avant l'équerrage final : les équerres se rattrapent en coulissant dans la rainure.

---

## Phase 2 — Pose des parois (fond + côtés)

1. **Fond** : insérer le Dibond (304×500 pour A, 248×500 pour B/C) dans les rainures des 4 rails bas.
2. **Côtés** : insérer les 2 panneaux (500×216) dans les rainures des rails haut/bas + montants.
3. **Fixation** : panneaux tenus par la rainure ; si jeu, 1–2 vis ponctuelles dans les montants.
4. **Contrôle** : cage ferme (panneaux suppriment le déversement).

> Faces avant/arrière ouvertes à ce stade (volets en Phase 3).

---

## Phase 3 — Faces avant/arrière (volets rabattables)

1. **Positionner** chaque volet (304×216 A / 248×216 B/C) sur son ouverture.
2. **Charnière piano** sur l'arête basse + rail bas (vis autotaraudeuses dans Dibond + vis/T-nuts dans le profilé).
3. **Loquet à bascule** en haut de chaque volet.
4. **Contrôle rabattement** : volet ouvert à plat (90°), sans accrocher.
5. **Préhension** : à décider — prise affleurante (creusée).

---

## Phase 4 — Table (coulisses double sens + HPL)

1. **Coulisses D5DD** : rails fixes sur la face interne des 2 rails de profondeur hauts (T-nuts M4), rails mobiles vissés sous la table HPL.
2. **Monter la table** : emboîter, vérifier coulisse double sens.
3. **Butée 300 mm** : vis/T-nut en butée si extension totale.
4. **Contrôle** : sortie 300 mm avant ET arrière, à plat, sans jeu.

---

## Phase 5 — Finitions et contrôles finaux

1. Aligner les 2 coulisses à la même hauteur.
2. **Assise** : 80 kg → stable, sans fléchir ni racler.
3. **Volets** : ouverture/fermeture, planéité au sol, loquets francs.
4. **Accès double sens** : volets avant + arrière.
5. **Conduite** : volets fermés + loquets, table rentrée (butée).
