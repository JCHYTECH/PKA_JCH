# Procédure de construction — Meuble banquette v7 (aluminium T-slot 2020)

> Construction par phases, dans l'ordre. Outillage nécessaire : **scie à métaux** (ou mini-meuleuse), **clé Allen**, **cutter**, **tournevis**, équerre, mètre, lime. Perceuse **optionnelle** (uniquement si on perce des panneaux).
> Références : `meuble-banquette-profiles-alu-v7.md` (design) · `meuble-banquette-profiles-alu-v7-plan.svg` (plan) · `meuble-banquette-profiles-alu-v7-coupes.xlsx` (coupes/BOM).

---

## Phase 0 — Préparation (coupes + commandes)

1. **Profilés** : couper les **44 profilés 2020** selon la liste de coupes (rails 540/344/288 mm, montants 216 mm). Scie à métaux, trait droit ; les cubes 3 voies absorbent ±1 mm.
2. **Panneaux** : faire découper par le fournisseur :
   - Dibond 3 mm : fonds, côtés, volets (rectangles simples).
   - HPL compact 12 mm : les 3 tables/assises, **angles avant arrondis R5–R10** (CNC).
3. **Quincaillerie** : coulisses Chambrelan D5DD (3 paires), 24 cubes 3 voies, T-nuts M5 + M4, charnières piano (6), loquets à bascule (6), visserie inox.
4. **Vérifier** : les coupes des 3 modules sont identiques (A = 344, B/C = 288 de large).

---

## Phase 1 — Construction métallique (ossature)

*Objectif : 3 cages 2020 carrées, sans panneaux.*

1. **Assembler la base** : 2 rails profondeur (540) + 2 rails largeur (344 ou 288), reliés par **4 cubes 3 voies** aux coins (T-nuts M5). Serrer modérément.
2. **Monter les 4 montants** (216 mm) sur les cubes de la base.
3. **Poser le cadre haut** : 4 rails sur les montants, 4 cubes 3 voies. Vérifier que les montants rentrent bien.
4. **Équerrage** : contrôler les diagonales (les 2 diagonales de chaque face doivent être égales) avant de **serrer à fond** les cubes.
5. **Répéter** pour les 2 autres modules.
6. **Solidarisation (optionnelle au banc)** : assembler A + B + C avec chevilles Ø8 + loquets à bascule aux interfaces, une fois les 3 cages alignées.

> ⚠️ Ne pas trop serrer les T-nuts avant l'équerrage final : les cubes 3 voies se rattrapent en coulissant dans la rainure.

---

## Phase 2 — Pose des parois (fond + côtés)

*Objectif : rigidifier la cage (effet diaphragme).*

1. **Fond** : insérer le panneau Dibond 3 mm (304×540 pour A, 248×540 pour B/C) dans les rainures des 4 rails bas. Il vient se poser sur le cadre bas.
2. **Côtés** : insérer les 2 panneaux latéraux (540×216) dans les rainures des rails haut/bas + montants avant/arrière.
3. **Fixation** : les panneaux restent en place par la rainure ; si un jeu apparaît, 1-2 vis ponctuelles dans les montants (pré-percer le Dibond).
4. **Contrôle** : la cage doit être ferme (les panneaux suppriment le déversement).

> Les faces avant/arrière restent **ouvertes** à ce stade (elles recevront les volets en Phase 3).

---

## Phase 3 — Faces avant/arrière (volets rabattables)

*Objectif : accès double sens par volets à 90°.*

1. **Positionner** chaque volet (304×216 pour A, 248×216 pour B/C) sur son ouverture avant/arrière.
2. **Charnière piano** : la fixer sur l'**arête basse** du volet et sur le **rail bas** du caisson (vis autotaraudeuses dans le Dibond + vis dans le profilé via T-nuts, ou rivets). Le volet doit basculer **vers l'extérieur**.
3. **Loquet à bascule** : en **haut** de chaque volet (côté intérieur), pour maintenir fermé en conduite.
4. **Contrôle rabattement** : le volet ouvert doit reposer **à plat sur le sol** (90°), sans accrocher. Ajuster la charnière si nécessaire.
5. **Préhension** : à décider plus tard — privilégier une **prise affleurante** (creusée) pour ne pas gêner la planéité une fois rabattu.

---

## Phase 4 — Table (coulisses double sens + HPL)

*Objectif : assise qui coulisse 300 mm vers l'allée OU l'extérieur.*

1. **Coulisses D5DD** : fixer les **rails fixes** sur la face interne des **2 rails latéraux hauts** du caisson, via **T-nuts M4** dans la rainure (coulissants, réglables — pas de perçage).
2. **Rails mobiles** : les visser **sous la table HPL** (pré-percer le HPL à travers les trous du rail). Centrer la table sur les 2 rails.
3. **Monter la table** : emboîter les rails mobiles dans les fixes, vérifier la coulisse **dans les deux sens**.
4. **Butée à 30 cm** : poser une vis/T-nut en butée dans chaque rainure (si la D5DD est en extension totale) pour limiter la sortie à **300 mm**.
5. **Contrôle** : la table sort de 300 mm vers l'avant ET vers l'arrière, à plat, sans jeu. Les T-nuts M4 permettent de rattraper l'alignement.

---

## Phase 5 — Finitions et contrôles finaux

1. **Réglage des coulisses** : aligner les 2 coulisses à la même hauteur (elles se règlent dans la rainure).
2. **Assise** : s'asseoir (80 kg) → la table doit rester stable, sans fléchir ni racler.
3. **Volets** : ouvrir/fermer chaque volet → planéité au sol, loquets francs.
4. **Accès double sens** : rabattre le volet avant, puis l'arrière → on atteint le caisson des deux côtés.
5. **Conduite** : volets fermés + loquets enclenchés ; la table rentrée (butée).
