## 0. Résumé exécutif

**Produit :** Spray cutané à base d'hydrocortisone acéponate (HCA) 0.584 mg/ml — traitement topique de la dermatite atopique canine (CAD) et des dermatoses inflammatoires/prurigineuses.

**Marché cible :** Chine — marché CAD ~¥3.5B (~$480M, 2024), croissance +25% YoY. 124M chiens/chats. Cortavance (Virbac) seul HCA spray enregistré depuis 10 ans. Aucun générique.

**Stratégie :** Vetalyx devient le Marketing Authorisation Holder (MAH) d'un spray HCA sous sa marque, fabriqué en marque blanche par un CDMO européen (idéalement Portugal), enregistré en Chine via MARA.

**Supply chain cible :** API HCA (Hovione, Portugal) → CDMO formulation + fill-finish (Ferraz Pharma ou Hovione Drug Product, Portugal) → Packaging Vetalyx → Distribution cliniques vétérinaires Chine.

**Investissement estimé :** 335-610k€ (développement + enregistrement). Time-to-market : 18-24 mois.

## 3. Supply Chain & Stratégie de fabrication

### 3.1 Architecture cible

```
┌──────────────────────────────────────────────────────┐
│              VETALYX (Marketing Authorisation Holder)  │
│         Enregistrement MARA Chine + EU (optionnel)     │
└──────────────────────┬───────────────────────────────┘
                       │
       ┌───────────────┼───────────────┐
       │               │               │
 ┌─────▼──────┐  ┌─────▼──────┐  ┌─────▼──────┐
 │ API HCA    │  │ CDMO Spray │  │ Packaging  │
 │ Hovione PT │  │ Ferraz PT  │  │ Vetalyx    │
 │ ou Curia ES│  │ ou Hovione │  │ FR/ZH      │
 │ GMP/ASMF   │  │ Drug Prod. │  │             │
 └────────────┘  └────────────┘  └─────────────┘
```

**Processus de fabrication :**
1. Vetalyx achète l'API HCA (poudre) chez Hovione/Curia → livraison au CDMO
2. CDMO fait la R&D formulation (stabilité corticoïde en solution/suspension + solvant volatile)
3. Fill-finish : remplissage en flacon pompe doseuse + étiquetage Vetalyx
4. Conditionnement secondaire + expédition vers la Chine
