# Vetalyx — Claims Matrix FR

> Document de référence pour toutes les communications commerciales, cliniques et réglementaires.
> Source : [[2026-05-26_VETALYX_Market_Evidence_Pack]] (EN) + analyse NotebookLM 2026-06-06.

---

## Message canonique

> **"VETALYX cartographie la sensibilisation aux IgE pour soutenir la prise de décision vétérinaire."**

Version longue (présentations, matériaux KOL) :
> VETALYX cartographie la sensibilisation aux IgE spécifiques chez le chien et le chat pour soutenir la décision vétérinaire dans les suspicions de maladie allergique, notamment l'atopie environnementale et la planification de l'immunothérapie.

---

## Ce que Vetalyx peut affirmer ✅

| Allégation | Formulation autorisée |
|---|---|
| Détection | Détecte la sensibilisation aux IgE spécifiques d'un allergène |
| Orientation clinique | Sert d'outil de support à la décision pour orienter la prise en charge de la dermatite atopique |
| Aide au régime | Aide à identifier les allergènes candidats pour un régime d'éviction ou une discussion sur l'immunothérapie |
| Usage | Réservé à l'usage professionnel vétérinaire |
| Interprétation | Les résultats doivent être interprétés avec l'anamnèse, les signes cliniques et le diagnostic différentiel |

---

## Ce que Vetalyx doit exclure ❌

| Terme / allégation interdite | Raison |
|---|---|
| "Diagnostique l'allergie" | Le test ne diagnostique pas l'allergie à lui seul |
| "Diagnostique l'allergie alimentaire" | Le régime d'éviction/provocation reste le gold standard |
| **"Intolérance"** | **Terme banni** — l'intolérance est non-IgE dépendante, hors du périmètre du test |
| "Remplace le régime d'éviction" | Le régime d'éviction reste la référence absolue pour l'alimentaire |
| "Prédit la réaction clinique" | Le test mesure une sensibilisation, pas une réponse clinique |
| "Panel universel européen" | Sans qualification régionale, l'allégation est fausse |

| Vitesse | 1–5 jours | 10–15 min | 15 min |
| Prix | 85–180 € | ~35–39 € | Très bas |
| CCD blockers | Intégrés | Documentés v1, intégrés v2 | Absents |
| Cible | Spécialistes / labos | **Cliniques généralistes** | Cliniques |

> Vetalyx n'est pas un précurseur technologique. C'est un **précurseur de modèle d'affaires** : allergologie de routine dans la clinique généraliste.

---

## Frontière alimentaire — règle d'or

Le panel alimentaire est classé **P2** (différé). Toute communication sur l'alimentaire doit :
1. Utiliser uniquement la formulation "aide à l'orientation d'un régime d'éviction"
2. Rappeler que le régime d'éviction/provocation reste le gold standard
3. Ne jamais utiliser le mot "intolérance"
4. Ne jamais présenter le résultat comme suffisant pour un diagnostic alimentaire autonome
