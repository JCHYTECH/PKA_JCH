# Plan d'action — WildLens

> Dobby 🦉 — 2026-11-15 · Journal hebdomadaire wildlife, tête de funnel ARTEON → L'Instant Lu
> Cadence : samedi · Architecture v2 : The Frame / The Shift / The Field · EN + FR/IT à venir

## Objectif

Devenir le magazine wildlife de référence des photographes naturalistes exigeants, et convertir les lecteurs vers L'Instant Lu (1ère analyse gratuite → payant).

## Baseline

- 4 éditions rédigées (#1 → #4). Ghost en pause, support contacté.
- Migration self-host décidée (VPS Hostinger KVM 1, domaine wildlens.arteon.be).
- Instagram préparé, aucune publication sans demande explicite de JC.

## Phase 1 — Infrastructure (semaines 1–2) · Forge + Dobby

1. Acheter le VPS Hostinger KVM 1 + installer Ghost self-host (datacenter UE).
2. DNS `wildlens` → IP du VPS ; configurer Mailgun (mails transactionnels).
3. Importer les 4 éditions + le thème custom (charte ARTEON : vert terrain #3D5A3E).
4. Vérifier : journal en ligne sur wildlens.arteon.be.

## Phase 2 — Éditorial (continu, hebdo) · JC + Dobby

1. Relire + publier l'édition #4 (feu vert JC).
2. Pousser les éditions #1 → #3 en brouillon puis en ligne.
3. Reprendre la cadence hebdo (samedi), structure v2 : The Frame (400–600 mots) · The Shift (200–300) · The Field (100–150).
4. Maturation de la section « essai/philosophie » (langage animal) — l'intégrer quand mûre.

## Phase 3 — Multilingue (semaines 3–4) · Jade + Forge

1. Traduire les éditions en FR + IT (Jade).
2. Builder le changeur de langue EN/FR/IT + détection géoloc IP (langue par défaut).

## Phase 4 — Distribution + monétisation (semaines 4–6) · Dobby + Forge + Vega/Miel

1. Instagram : couche de découverte (publication sur demande explicite JC uniquement).
2. Funnel de conversion : WildLens → arteon.be/wildlens → CTA L'Instant Lu → 1ère analyse gratuite → payant.
3. Brancher la monétisation (cf. `monetisation-positionnement.md`) : presets 29 € + L'Instant Lu 1,90 €.

## Jalons

- ✅ S2 — Ghost self-host en ligne.
- ✅ S3 — 4 éditions en ligne + cadence hebdo.
- ✅ S4 — multilingue EN/FR/IT.
- ✅ S6 — funnel connecté à la monétisation.
