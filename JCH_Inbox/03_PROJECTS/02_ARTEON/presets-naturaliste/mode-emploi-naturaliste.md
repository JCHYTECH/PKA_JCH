## Ce que contient le pack

Chaque look existe en **3 forces** : **Standard** (nom de base = 100 %), **- Doux** (40 %), **- Fort** (200 %). Choisis la force selon l'intensité voulue.

## La philosophie : un seul regard, pas une pile de filtres

Ces presets incarnent **un rendu, pas vingt** : ombres veloutées teintées indigo, hautes lumières dorées, grain argentique fin, désaturation sélective, courbe en S avec lift des noirs. Le même geste photographique décliné selon le sujet.

## Installation

### Lightroom Classic (LrC)

1. Ouvrir le module **Développement**.
2. Ouvrir le panneau **Préréglages** (à gauche).
3. Clic droit sur **« Préréglages utilisateur »** → **Importer**.
4. Sélectionner les 12 fichiers `.xmp`.

*(Alternative : glisser-déposer les `.xmp` directement sur la photo.)*

### Lightroom CC (cloud)

1. Module **Édition** → **Préréglages**.
2. Cliquer **« ⋯ »** (trois points) → **Importer des préréglages**.
3. Sélectionner les 12 fichiers `.xmp`.

---

## Utilisation

1. Appliquer le preset sur la photo.
2. Ajuster **exposition** et **balance des blancs** à *votre* image — le preset donne la direction, pas la valeur exacte.
3. Ajuster la **vignette** selon votre cadrage.

---

## Quel preset pour quelle image

- Oiseau sombre (corbeau, corvidé, rapace) → **Plumage sombre**
- Oiseau blanc (héron, cygne, aigrette) → **Plumage clair**
- Oiseau coloré (martin-pêcheur, rollier, guêpier) → **Plumage coloré**
- Mammifère (renard, cerf, lièvre) → **Mammifères**
- Nuit / lumière artificielle → **Nocturne**
- Insecte, petit sujet → **Macro**
- Oiseau en vol, ISO haut → **Action / vol**
- Milieu, habitat, paysage → **Paysage**
- Image monochrome → **Noir & blanc**
- Contre-jour, brume, silhouette → **Contre-jour / brume**
- Lever / coucher, lumière chaude → **Golden hour**
- Tout le reste → **Signature Fin Art Cinématique**
