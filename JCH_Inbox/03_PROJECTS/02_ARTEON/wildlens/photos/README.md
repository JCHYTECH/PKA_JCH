# Photos WildLens

> Dossier canonique des photos destinées aux éditions WildLens.
> JC y dépose ses exports Lightroom (renommés) ; Dobby les uploade dans Ghost
> et les pose en couverture de l'édition correspondante.

## Convention de nommage

`<date-édition>-<sujet>.jpg`

Exemples (numérotation Ghost — renumérotée le 15/11) :
- `2026-10-31-rouge-gorge-retouche.jpg` (édition #1 — publiée 18/11)
- `2026-07-02-gannet.jpg` (édition #2 — programmée 05/12)
- `2026-03-28-roxanne-overton.jpg` (édition #3 — programmée 28/11)
- `2026-10-24-rouge-gorge.jpg` (ancienne #3 « Was this real? » — retirée de Ghost)

## Workflow

1. JC exporte depuis Lightroom et dépose le fichier ici (ou indique son chemin).
2. Dobby uploade dans Ghost (`Admin API images/upload`) et le pose en `feature_image` de l'édition.
3. Légende / crédit : `© JC Havaux / ARTEON`.

> Les anciens exports « LrC to-NN.jpg » (références dans les `Notes de publication`) sont à remplacer par les fichiers ici, avec des noms explicites.
