## Règle de conduite

1. **Avant d'émettre un prix** → chercher dans ce registre. Si absent → rechercher sur le web (DuckDuckGo, Amazon, idealo).
2. **Noter la source** : URL + date de consultation.
3. **Ne jamais extrapoler** : un prix vu il y a 3 mois n'est plus valide.
4. **Facteur d'erreur acceptable** : ±15%. Au-delà, c'est une faute de décision.
