# Roadmap long terme — PKA_JCH

> Vision 1 an / 3 ans / 5 ans. Complément de `roadmap-90-jours.md` (court terme).

---

## Horizon 1 an — juillet 2027

**PKA système**
- [ ] Architecture documentée et versionnée (`principes-architecturaux.md`)
- [ ] Multi-modèle stable : DeepSeek, Claude, Gemini, Qwen — chacun a son rôle documenté
- [ ] Knowledge graph (graphify) mature et utilisé systématiquement
- [ ] Sécurité documentée et auditée

**Projets**
- [ ] WildNexus : prototype terrain validé (capteurs + edge AI + radio)
- [ ] InsectNet : dataset opérationnel, pipeline entraînement automatisé
- [ ] IOT Van : HA + Zigbee/ESP32 + PV PI entièrement fonctionnel
- [ ] Vetalyx : partenariat/gamme clarifié

**Infrastructure**
- [ ] M1 Mac Studio : LLM local (Ollama/LM Studio) + datasets
- [ ] RPi Lupo : HA stable, backup testé
- [ ] NAS ou équivalent : centralisation données projets lourds

---

## Horizon 3 ans — juillet 2029

**PKA système**
- [ ] PKA est une plateforme : nouveaux outils se branchent sans friction
- [ ] Agents spécialistes autonomes pour les tâches répétitives (inbox, procurement, BOM)
- [ ] Documentation générée automatiquement à partir du code et des décisions

**Projets**
- [ ] WildNexus : produit commercialisable (kit ou SaaS)
- [ ] InsectNet : publié (dataset public + modèle open-source)
- [ ] Le réseau PKA couvre l'ensemble des projets actifs sans dispersion

**Infrastructure**
- [ ] Architecture cloud ou hybride si nécessaire (European DC)
- [ ] Indépendance énergétique partielle (panneaux + batterie)

---

## Horizon 5 ans — juillet 2031

**PKA système**
- [ ] PKA fonctionne avec des modèles majoritairement locaux (souveraineté)
- [ ] Agents capables de gérer des projets de bout en bout avec supervision humaine minimale
- [ ] Le Vault PKA est une référence consultable par d'autres (knowledge base publique ou semi-publique)

**Projets**
- [ ] WildNexus : autofinancé, équipe dédiée
- [ ] Impact écologique mesurable (hectares surveillés, espèces détectées)
- [ ] Nouveaux projets nés de PKA, alignés sur la mission initiale

**Infrastructure**
- [ ] Redondance et résilience : aucun point de défaillance unique
- [ ] Zéro dépendance à un SaaS critique
