# Chronophotographie Numérique : Workflow Action Overlay

## Vue d'ensemble
Technique permettant de décomposer un mouvement rapide (vol d'oiseau, saut, course) en superposant plusieurs frames d'une rafale sur une seule image finale.

## Étape 1 : Développement & Sync (Lightroom/DxO)
1. Sélectionner la série de photos.
2. Développer l'image "maîtresse" (la plus forte visuellement).
3. Synchroniser les réglages sur toute la série.
4. Exporter : **Modifier dans > Ouvrir en tant que calques dans Photoshop**.

## Étape 2 : Alignement Automatique
1. Sélectionner tous les calques dans Photoshop.
2. **Édition > Alignement automatique des calques...** > Mode "Auto".
3. Recadrer pour supprimer les bords transparents.

## Étape 3 : Fusion & Masquage (Méthode Nova 🦋)
1. Placer l'image finale en bas de la pile (Opacité 100%).
2. Pour les autres calques :
   - Ajouter un **Masque de fusion noir** (Alt + Clic sur l'icône Masque).
   - Peindre en **Blanc** avec un pinceau doux (opacité 30-70%) sur le sujet.
   - *Astuce densité :* Plus l'image est éloignée dans le temps de l'image finale, plus son opacité globale doit être faible.

## Étape 4 : Optimisation (Lynx 🐆)
- Vérifier les chevauchements (ailes, pattes).
- Harmoniser le grain et le bruit numérique sur l'ensemble du composite.
