# 🦉 Continue + NVIDIA — Fiche Dummies

> Ta config : 7 modèles gratuits NVIDIA via l'extension Continue dans VS Code.

---

## 🚀 DÉMARRAGE RAPIDE

| Tu veux... | Tu fais |
|------------|---------|
| Ouvrir le chat | **Cmd+L** dans VS Code |
| Changer de modèle | Menu déroulant en haut du chat |
| Redémarrer Continue | **Cmd+Shift+P** → tape `reload` → Entrée |

**Règle d'or :** dis ce que tu fais, où est le problème, ce que tu veux.

---

## 📎 DONNER DU CONTEXTE

| Méthode | Comment |
|---------|---------|
| Mentionner un fichier | Tape `@` puis choisis un fichier dans la liste |
| Envoyer le fichier ouvert | **Ctrl+Enter** (ou Cmd+Enter) |
| Mentionner un dossier | `@folder` |

---

## ⚡ ASTUCES

- **Tab** = accepter une suggestion de code
- **Esc** = refuser
- **Cmd+I** = poser une question sur la ligne sélectionnée
- Si le modèle ne répond pas, change de modèle (le menu déroulant en haut)

---

## 🔧 DÉPANNAGE

| Problème | Solution |
|----------|----------|
| Plus aucun modèle ne marche | Reload Continue : **Cmd+Shift+P** → `Continue: Reload` |
| "Operation not permitted" | Contacte Dobby, c'est l'API key ou la config |
| Modèle lent / timeout | Passe sur ⚡ Mixtral ou 💻 Llama 3.1 |
