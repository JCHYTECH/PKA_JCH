# Skill — competitive-framework

> « Aide-moi à identifier où je suis réellement en compétition avec [domaine] et conçois une stratégie pour briser mes limitations auto-imposées. » — prompt source Instagram @callme.wisdomhunter.

## Pourquoi

Les projets business PKA (ARTEON, WildLens, VETALYX) n'ont pas de réflexion de positionnement formalisée. Ce skill force la question « contre qui — ou contre quoi — on joue vraiment ? ». La réponse n'est presque jamais le concurrent évident : c'est souvent un substitut, le statu quo, ou une croyance limitante.

## Les 3 questions

1. **Contre qui ?** — concurrents directs **et** indirects (substituts, statu quo, « ne rien acheter », « le faire soi-même »).
2. **Sur quoi ?** — le critère réel de choix (prix, qualité, confiance, temps, singularité).
3. **Quelle limite auto-imposée ?** — la croyance ou l'habitude qui restreint le champ (ex. « je dois être parfait avant de publier », « ce marché est saturé »).

## Procédure

1. Cadrer le projet/domaine (ARTEON, WildLens, VETALYX, autre).
2. Dresser la **carte concurrentielle réelle** : directs + substituts + statu quo.
3. Identifier les **2–3 limitations auto-imposées**.
4. Proposer une **stratégie** pour briser la plus contraignante (déplacement du terrain de jeu, différenciation, nouvelle catégorie).

## Règles

- **Ne pas se limiter aux concurrents évidents** — chercher les substituts et le statu quo, c'est là qu'est le vrai jeu.
- **La limitation auto-imposée est le levier** — c'est elle qui change la trajectoire, pas un benchmark de plus.
- **Respecter le scope des projets** (pas de scope creep) — cf. `wildnexus-governance` pour WildNexus P0.

## Déclencheurs

- « competitive framework », « positionnement », « analyse concurrentielle »
- « contre qui on joue ? », « où je suis en compétition »

## Livrable

Carte concurrentielle + stratégie, rendue dans le chat et sauvegardée dans le projet concerné (`03_PROJECTS/<projet>/`).

## Skills liés

- **`conseil`** — stress-tester la stratégie une fois posée (prémortem sur le positionnement).
- **`arbor-research`** — si la stratégie ouvre une question d'hypothèses à explorer.
- **`seo-competitor-pages` / `seo-cluster`** — pour la déclinaison SEO concrète une fois le positionnement choisi.
